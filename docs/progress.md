接下来按以下顺序推进；已完成的资料检索不再作为后续待办：

1. 实现六情、六欲、逐人好感和变化记录，将初值与计算规则整理为可配置参数。
2. 接入聊天经历识别、可信来源归因和末尾状态区表达要求；与记忆维护共用分析入口，重读旧内容不重复计分。
3. 接入由情绪状态驱动的作息、逐人求助、主动聊天、心愿、不满和满值事件；三种冷落/断联机制各自可选。现有可选作息和主动发言不等于这些后续机制已经完成。
4. 补齐页面、曲线和查询，检查重复计分、跨日、恢复、关闭后的残留、状态退出和跨会话泄露。

表中“已完成”指实现与本地验证完成，不代表真实部署、模型表达、协议端兼容性或服务端缓存命中已经实测。测试方法、覆盖范围与验收标准见 [TESTING.md](../TESTING.md)。

后续完成一项工作时，在此更新状态和顺序，在对应功能文档更新实际行为，在测试清单更新验证范围；不再向各文档追加一份“下一步”。
